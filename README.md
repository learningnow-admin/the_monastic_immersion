# The Monastic Immersion

A one-page web app for a small group that consumes cultural artifacts together.
Each session gathers artifacts (one share per seat, two for the couple's
shared seat, five at most); three are enough
to lock a day, and anything past three is a bonus. Days can be proposed and
voted on from the start. Whoever offers first hosts (default: Nina's house);
meet (7:30 pm, always), mark it done, and the next session begins with a day
four weeks on already proposed.

A seat can sit a session out any time before the session is done: its
artifacts are withdrawn, hosting is handed back, and it leaves the vote marks
so nobody waits on it. Rejoining restores the share and any earlier votes.
The quorum stays at three and bends down only when the seats still in can't
reach it. Absences are per session; everyone is back in when the next begins.

## Stack

- **Squint** (`src/worker.cljs`) — Clojure syntax compiled to a plain JS module.
  The compiled `src/worker.mjs` is gitignored; `npm run build` regenerates it.
- **Cloudflare Worker** (`src/index.mjs` entry) serving server-rendered HTML,
  plain form POSTs, zero client-side JavaScript.
- **D1** (SQLite) for storage; schema in `migrations/`.

## Identity & security

Each member has a personal secret link: `/m/<token>`. The server resolves who
is acting from the token on every request — form fields are never trusted for
identity, so members cannot act as each other. The bare root URL shows nothing.
Members are pseudonymous (Nina, Kai, Ada, and Otto & Cass, a couple sharing one
seat and one link); tokens are random 18-hex strings generated by the migration.

List everyone's links:

```sh
npx wrangler d1 execute tmi --remote --command "SELECT name, token FROM members"
```

If someone's link leaks, reissue it:

```sh
npx wrangler d1 execute tmi --remote --command "UPDATE members SET token = lower(hex(randomblob(9))) WHERE name = 'Kai'"
```

## Local development

```sh
npm install
npm run db:local     # apply migrations to the local sqlite
npm run dev          # build + wrangler dev on http://localhost:8787
```

Get local test links with the `--local` variant of the token query above.
To reset local data: delete `.wrangler/state` and run `npm run db:local` again.

## Deploying (first time)

1. `npx wrangler login`
2. `npx wrangler d1 create tmi` — copy the returned `database_id` into
   `wrangler.toml`.
3. `npm run db:remote`
4. `npm run deploy` — the URL is printed at the end.
5. Run the token query above and send each member their personal link.

After that, updates are just `npm run deploy`.

Tweakables in `src/worker.cljs`: `meeting-time`, `meeting-place` (the default
when nobody offers to host), `slots` (most artifacts per session), `quorum`
(artifacts needed to lock a day), `shares` (per-seat allowance, for shared
seats), `artifact-types`, `rules`, `procedure`, `influences`. Renaming a member touches three tables:

```sh
npx wrangler d1 execute tmi --remote --command "UPDATE members SET name='NewName' WHERE name='Kai'; UPDATE artifacts SET member='NewName' WHERE member='Kai'; UPDATE votes SET member='NewName' WHERE member='Kai'"
```
